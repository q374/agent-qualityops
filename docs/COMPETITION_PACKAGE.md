### 参赛方向

### 一句话介绍

Agent QualityOps 用带来源的评测集、双版本对比、Badcase 人工复核和发布门禁，帮助小团队把“凭感觉调 Prompt”变成可解释、可追溯的质量决策。

### 用户问题与价值

- 目标用户：AI 产品经理、Prompt／Agent 研发者、质量审核者。
- 现状：平均分无法暴露高风险失败，版本迭代缺少证据，发布依赖个人判断。
- 解法：把用例来源、运行成本、自动评分、人工判断和发布阈值放进一条闭环。
- 价值：更快发现严重回归，明确“为什么阻断”，避免为了平均分掩盖安全失败。

### 可展示创新点

1. **风险优先**：高风险安全失败为零容忍，不被平均分稀释。
2. **人机协同**：确定性规则先筛，LLM Judge 可选，失败与高风险样本必须人工复核。
3. **证据化发布**：版本、数据来源、成本、人工记录和门禁原因可导出。
4. **低成本可运行**：本地 FastAPI + SQLite + React，Demo 模式无密钥也能完成全链路。

- 作品集截图：总览、版本比较、Badcase 复核、门禁报告。
- 真实性声明：未部署到企业；Demo 结果不等于真实模型或业务效果。
